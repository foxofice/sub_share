/ 02 — FEATURES

它只做三件事

克制、专注，把字幕检索这件事做到顺手。

01

更新数据库

根据本地字幕数据生成数据库，保留一份可离线检索的快照。主要给字幕上传者使用，改完即更新。

02

高级查找

按分类、年份、扩展名等条件自由组合。不熟悉 SQL 也能用图形界面，轻松筛选想要的结果。

03

类 SQL 查询

熟悉的话，直接用类似 SQL 的语法精确查找 —— 这是这款工具最硬核的浪漫。

query.sdb
[time] >= '2010.1.1' and [time] <= '2011.1.1' and
[extension] like '%srt%'

/ 03 — SUBMISSION SPEC

放进来的字幕，要长这样

UTF-8 统一的目录结构与编码，让每一份字幕都找得到、看得懂。

subs_list/ — 目录结构 
<type>/
└─ <year>/
   └─ (<date>)<name>/
      ├─ info.txt                 # 影片说明（可忽略）
      └─ <source>/
         └─ <sub_name>/
            ├─ 01.ass              # 字幕文件
            └─ 02.ass
   # <sub_name>.txt  # 字幕补充说明
TYPE

分类：animation（动画）、movie（电影）、R18，可按需自定添加。

DATE

放送年份与日期，如 (2015.7.4)；不确定时可写 (1998) 或 (1998.5)。

SOURCE

匹配源：BD / TV / Web / test 等，尽量统一便于查找。

ENCODING

所有文本格式文件请统一使用 UTF-8 编码，保证多语言兼容。
